# Sales Forecast Prediction

A data analysis project focused on analyzing sales performance over time using transactional sales data and time-series visualization techniques.

## What it does

* Cleans and preprocesses sales data
* Converts and processes date columns for time-based analysis
* Aggregates sales by date to identify trends
* Visualizes sales growth and fluctuations using line charts
* Creates lagged features for time-series forecasting analysis

## Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

## Conclusion

* Time-series analysis helped identify sales patterns and business trends
* Visualizations provided insights into sales growth and fluctuations over time
* Lag feature engineering prepared the dataset for forecasting and predictive modeling
